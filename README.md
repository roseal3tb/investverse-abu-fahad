# جوال أبو فهد المفقود — INVESTVERSE

موقع تفاعلي مستقل لحملة «ضاع جوال أبو فهد ومعه سرّ صفقته الرابحة».

## ماذا يقدم الموقع؟

الموقع يبدأ بشاشة قفل جوال أبو فهد، وتظهر ثلاث إشعارات من قروب التوصيات وأم فهد وبنك إثمار. بعد السحب أو الضغط للفتح، يكتشف الزائر **ستة تطبيقات متاحة** وتطبيق **INVESTVERSE** واحدًا مقفولًا. يتصفح القصص والملاحظات والصور للعثور على أربع أرقام بجوار نجمة ⭐، ثم يدخل الرمز لفتح دعوة المعرض.

المشروع **مستقل تمامًا**، ولا يغيّر شيئًا في ريبو `roseal3tb/INVESTVERSE` ولا يحتاج خادم API أو قاعدة بيانات.

### التعليمات السريعة

- افتح `index.html` في متصفح حديث، أو شغّل السيرفر المحلي:

```bash
python3 -m http.server 5173
```

ثم افتح `http://localhost:5173`.

- يمكن أيضًا نشر مجلد المشروع مباشرة على Vercel (Framework Preset: **Other**، ولا يوجد أمر Build مطلوب)، أو Netlify، أو GitHub Pages.

### بيانات المعرض التي تحتاج اعتمادًا

افتح الملف `config.js` وعبّئ القيم التالية **بعد التأكد منها**:

| المفتاح | الغرض |
|---|---|
| `eventDate` | تاريخ ووقت المعرض الرسمي |
| `eventLocation` | اسم موقع المعرض الرسمي |
| `registrationUrl` | رابط التسجيل `https://...` |
| `mapUrl` | رابط الخريطة `https://...` |
| `eventNotes` | ملاحظات اختيارية في الدعوة |

تركناها فارغة لأن ملف الحملة لم يحدد هذه المعلومات. عند عدم تعبئتها، يظهر في الدعوة `[التاريخ والوقت]` و`[المكان]`؛ وأزرار التسجيل والخريطة توضّح أن الروابط لم تُحدد بدل التوجيه إلى رابط غير صحيح.

### الرمز وطريقة اللعب

الترتيب المطلوب في الملف:

1. **٤** — واتساب ← أبو سعد ← «الشقة بالدور ٤ ⭐».
2. **٢** — المنبّه ← «⭐ لا تنسى» في الساعة ٢:٠٠.
3. **٩** — الملاحظات ← «مواعيد» ← عشاء الخميس الساعة ٩ ⭐.
4. **٨** — الصور ← صورة تيشيرت فهد رقم ٨ ⭐.

**الرمز النهائي 4298**. يمكن إدخاله باستخدام لوحة الأرقام أو لوحة المفاتيح الفعلية. بعد ثلاث محاولات خاطئة تظهر رسالة «تأكد إنك شفت كل ⭐». بعد الدخول الصحيح تظهر الدعوة؛ **لا يتم كشف سر الصفقة** قبل المعرض.

## الهوية البصرية

- الشعار والأيقونة مستخرجان مباشرة من ملف `مقترح شعار Invest verse(1).pdf` المرفق من صاحب المشروع.
- الألوان المعتمدة: `#205D3B`، `#306E45`، `#6CB579`، `#4B4A4A`، `#E8E8E8`.
- يحدد ملف الهوية الخطين **29LT Bukra Wide / 29LT Bukra**. الخط الأصلي لم يكن مرفقًا بصيغته القابلة للاستخدام في الويب، لذلك يبحث CSS عنه أولًا ثم يستخدم خط Tajawal أو خطًا عربيًا بديلًا. لا يوجد ملف خط خاص مضمّن.
- الصور الثماني في `assets/photos/` **صور مُنشأة للحملة** وليست صورًا أصلية لأشخاص أو حدث حقيقي، ويمكن استبدالها بصور يقرّها الفريق مع الحفاظ على أسماء الملفات.

## التحقق

```bash
python3 tests/test_site.py
```

الاختبارات الأساسية تستخدم مكتبة Python القياسية. تشغيل الاختبارات المرئية التفاعلية يتطلب تثبيت **Python Playwright** ومتصفح **Chromium**. عند توفرهما تُختبر الرحلة الكاملة والرمز والأزرار وحالات الهاتف والكمبيوتر. في بيئة التطوير الحالية نجحت مجموعات الاختبار الخمس، بما فيها الاختبار التفاعلي الكامل.

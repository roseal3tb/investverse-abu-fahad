# جوال أبو فهد المفقود — INVESTVERSE

موقع تفاعلي مستقل لحملة «ضاع جوال أبو فهد ومعه سرّ صفقته الرابحة».

## ماذا يقدم الموقع؟

الموقع يحاكي جوال آيفون بالوضع الداكن: شاشة قفل بساعة وتاريخ حقيقيين وثلاث إشعارات، تُسحب للأعلى لفتح الجوال. الشاشة الرئيسية **صفحتان** مع Dock ثابت:

- **الصفحة الأولى:** ودجت البطارية والصور، ثم التقويم، الساعة، الملاحظات، App Store، الإعدادات.
- **الصفحة الثانية:** واتساب، Gmail، **INVESTVERSE المقفول برمز**، الأغاني، بنك إثمار.
- **الـDock:** الهاتف، Safari، الكاميرا، الصور.

يتصفح الزائر الجوال، يلقى الرمز في ملاحظة «حساباتي 🔑» داخل تطبيق الملاحظات، ثم يدخله فيفتح التطبيق على بوستر المعرض.

تفاصيل المحاكاة:

- **التنقل مثل iOS:** التطبيق يفتح من أيقونته ويرجع لها، الصفحات الداخلية تنزلق، والرجوع للرئيسية بسحب الشريط السفلي للأعلى (أو الضغط عليه، أو زر Esc). التنقل بين صفحتي الشاشة الرئيسية بالسحب يمين ويسار (بالإصبع أو الماوس)، أو بالضغط على النقطتين، أو بالأسهم.
- **الأيقونات:** مرسومة خصيصًا للمشروع داخل `script.js` (`appArt`)، وليست أيقونات أبل أو واتساب أو Gmail الأصلية.
- **البطارية:** تبدأ ٢٥٪ وتنزل ١٪ كل ٣٠ ثانية حتى ١٠٪. عند ٢٠٪ و١٠٪ يظهر تنبيه «البطارية منخفضة» بزرّي «نمط الطاقة المنخفضة» و«إغلاق»، ومؤشر البطارية يصير أحمر (أو أصفر مع نمط الطاقة المنخفضة). القيم في أعلى `script.js` (`BATTERY_START`، `BATTERY_FLOOR`، `BATTERY_STEP_MS`، `BATTERY_ALERTS`).
- **الخلفية:** `assets/wallpaper.webp` لشاشة القفل والشاشة الرئيسية.
- **داخل التطبيق المقفول:** `assets/investverse-poster.webp`.
- على الكمبيوتر يظهر الجوال داخل إطار، وعلى الجوال يملأ الشاشة.

المشروع **مستقل تمامًا**، ولا يغيّر شيئًا في ريبو `roseal3tb/INVESTVERSE` ولا يحتاج خادم API أو قاعدة بيانات. الخطوط مضمّنة داخل `assets/fonts/` فلا يحتاج اتصالًا بخدمات خارجية.

### التعليمات السريعة

- افتح `index.html` في متصفح حديث، أو شغّل السيرفر المحلي:

```bash
python3 -m http.server 5173
```

ثم افتح `http://localhost:5173`.

- يمكن أيضًا نشر مجلد المشروع مباشرة على Vercel (Framework Preset: **Other**، ولا يوجد أمر Build مطلوب)، أو Netlify، أو GitHub Pages.

### بيانات المعرض

موعد المعرض ومكانه معروضان في البوستر نفسه. لاستبدال البوستر غيّر الملف `assets/investverse-poster.webp` بنفس الاسم.

الملف `config.js` اختياري: إذا عبّأت `registrationUrl` أو `mapUrl` (روابط `https://`) يظهر تحت البوستر زر «سجّل حضورك» أو «الخريطة»، و`eventNotes` تضيف سطر ملاحظات. إذا تُركت فارغة لا يظهر أي زر.

### الرمز وطريقة اللعب

الرمز مكتوب صريحًا في تطبيق الملاحظات، ملاحظة «حساباتي 🔑»:

- الإيميل: `abufahad@gmail.com`
- الباسوورد: `abufahad12345`
- باسوورد البرنامج: `4298`

**الرمز النهائي 4298**. يُدخل بلوحة الأرقام على الشاشة أو بلوحة المفاتيح الفعلية. زر «نسيت الرمز؟» يعطي تلميحًا بأن أبو فهد يكتب كلمات السر في الملاحظات، وبعد ثلاث محاولات خاطئة تظهر رسالة توجّه للملاحظة. بعد الدخول الصحيح يظهر بوستر المعرض؛ **لا يتم كشف سر الصفقة** قبل المعرض.

## الهوية البصرية

- الشعار والأيقونة مستخرجان مباشرة من ملف `مقترح شعار Invest verse(1).pdf` المرفق من صاحب المشروع.
- الألوان المعتمدة: `#205D3B`، `#306E45`، `#6CB579`، `#4B4A4A`، `#E8E8E8`.
- يحدد ملف الهوية الخطين **29LT Bukra Wide / 29LT Bukra**. الخط الأصلي لم يكن مرفقًا بصيغته القابلة للاستخدام في الويب، لذلك يبحث CSS عنه أولًا ثم يستخدم خط Tajawal أو خطًا عربيًا بديلًا. لا يوجد ملف خط خاص مضمّن.
- واجهة الجوال نفسها تستخدم خط النظام على أجهزة أبل وخط IBM Plex Sans Arabic على غيرها، وخط Tajawal لشاشة البوستر.
- الصور الثماني في `assets/photos/` **صور مُنشأة للحملة** وليست صورًا أصلية لأشخاص أو حدث حقيقي، ويمكن استبدالها بصور يقرّها الفريق مع الحفاظ على أسماء الملفات.

## التحقق

```bash
python3 tests/test_site.py
```

الاختبارات الأساسية تستخدم مكتبة Python القياسية. تشغيل الاختبارات المرئية التفاعلية يتطلب تثبيت **Python Playwright** ومتصفح **Chromium**. عند توفرهما تُختبر الرحلة الكاملة والرمز والأزرار وحالات الهاتف والكمبيوتر. الاختبارات السبعة تغطي الرحلة الكاملة، صفحتي الشاشة الرئيسية والتطبيقات الجديدة، تنبيهات البطارية، لوحة المفاتيح، ومقاسات الجوال والكمبيوتر. لتحديد مسار المتصفح: `CHROMIUM_PATH=/path/to/chrome python3 tests/test_site.py`.
